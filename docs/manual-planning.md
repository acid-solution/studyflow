# 手动规划与放弃操作

核对日期：2026-10-17。先确定目标结果，再编排学习计划；保存草稿与启用执行分别发生。

## 新建目标

在目标页点击新建，填写名称，可选完成标准、目标日期与说明。不选所属目标建立顶层节点，选择已有目标建立分目标；选择器显示路径，编辑排除自身和后代。

目标卡片可以直接添加计划或分目标。一个目标可以有多个并行计划，不要求先拆分；但没有任何必要子项的目标不能直接确认达成。

## 两步创建计划

1. 选择所属目标，填写计划名称与必填计划目标，可补充完成标准、目标日期、说明。缺目标时在原表单内新建，返回后保留已填内容。
2. 选择按日期或按课时，填写每周预计投入（小时）及可选参考起止日期，最终点击创建并安排任务。

服务端在最终提交时创建计划与 V1 草稿；返回前一步不创建数据。页面小时转换为整数分钟。目标日期属于计划，推进方式、周期和预算属于版本。

## 编排与激活

可直接添加任务，也可先创建阶段并在阶段内连续添加。任务可填说明和预计分钟，阶段可填成果；保存后继续添加会明确提示上一项结果。

日期任务允许暂不排日期，课时任务不显示日期字段。保存阶段、任务均是独立持久化操作，中途离开可以继续已有草稿。用户主动激活版本后，任务进入日常执行视图。

创建空白新版本与复制版本使用表单。复制不把后续来源修改同步过来，详见[领域规则](../STUDYFLOW_V2_PLAN.md)。

## 编辑保护

提交期间禁用重复操作，失败保留输入。关闭未保存表单时确认；弹窗管理键盘焦点，窄屏可滚动。

编辑保留原乐观锁版本；其他客户端修改后提示核对，不偷换版本号。计划或版本变为只读、阶段删除、模式变化时，保留输入并阻止不再合法的保存。

## 放弃与账号默认

默认每次询问。放弃目标或计划时选择“从上层判断排除”或“继续阻塞上层”，两个选项互斥；顶层目标没有上层影响选项。

明确勾选以后按此选择直接操作后，将结果保存为账号偏好。设置页可以改为默认排除、默认阻塞或恢复询问，影响今后操作，不重写既有放弃项。放弃不级联放弃下属内容，保留进度与历史。

放弃失败不保存新的默认；业务成功但偏好保存失败时明确提示，到设置重试，不重复放弃。偏好读取失败则停止并允许重试。

`GET/PATCH /api/v1/preferences` 的 `default_abandon_parent_effect` 为 `ask`、`exclude` 或 `block`。迁移给既有账号设置 `ask`，不自动开启跳过确认。
